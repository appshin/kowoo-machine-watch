# 코우타이 설비 가동 감시 (KOWOO Thai Machine Watch)

공장 CCTV 영상에서 **설비 앞 작업자 위치에 사람이 없는 설비**를 실시간으로 찾아 빨간 박스로 표시하고,
코우타이 관리자와 한국 본사가 같은 화면(GitHub Pages)에서 보면서 관리하는 웹입니다.

## 구성

```
[CCTV/NVR] --RTSP--> [공장 분석 PC]
                       go2rtc (영상 변환, 127.0.0.1 전용)
                       analyzer.html (Chrome, 사람 인식 + 설비별 판정)
                            |
                            v
                   Firebase Realtime Database (asia-southeast1)
                   상태 / 이벤트 / 근무조 통계 / 보고 있을 때만 영상 프레임
                            ^
                            |
     [GitHub Pages] index.html  <-- 코우타이 관리자 (PC, 휴대폰), 한국 본사
```

- **판정 방식**: 설비마다 "설비 박스"와 "작업자 위치"를 영상 위에 그려 두면, 작업자 위치에 사람이 정해진 시간(기본 60초) 이상 없을 때 그 설비를 **비가동(빨간 박스)** 으로 표시합니다.
- **사람 인식**: Google MediaPipe(EfficientDet) 모델이 분석 PC의 브라우저 안에서 돌아갑니다. 영상이 외부 서버로 나가지 않습니다.
- **원격 영상**: 대시보드에서 누군가 해당 카메라를 보고 있을 때만 2초마다 한 장씩 올라갑니다. 영상은 저장되지 않고 최신 1장만 덮어씁니다.
- **기록**: 비가동 시작/종료 이벤트, 근무조(주간 08–20시 / 야간 20–08시, 현지시간)별 설비별 가동·비가동 시간.
- **계획정지**: 생산계획상 돌리지 않는 설비는 대시보드에서 "계획정지 처리"하면 빨간 표시와 통계에서 빠집니다.
- **언어**: 한국어 / English / ไทย (화면 오른쪽 위에서 전환)

| 파일 | 역할 |
|---|---|
| `index.html` | 관리 대시보드 (안돈 보드, 실시간 영상, 비가동 목록, 근무조 통계, 기록) |
| `analyzer.html` | 공장 분석 PC 전용 화면 (카메라 등록, 설비 영역 그리기, 분석 실행) |
| `assets/firebase-config.js` | Firebase 설정값, 근무조 시각, 구역(F1/F2/F3/창고) |
| `database.rules.json` | DB 보안 규칙 |
| `edge/` | 분석 PC용 go2rtc 설정 예시, 자동 시작 배치파일 |

## 1단계. Firebase 준비

기존 `kowoo-status` 프로젝트를 같이 써도 되고 새 프로젝트를 만들어도 됩니다. 데이터는 모두 `cctv/` 아래에 들어가서 기존 데이터와 겹치지 않습니다.

1. Firebase 콘솔 > **Realtime Database** 생성 (위치: `asia-southeast1` 싱가포르).
2. **Authentication** > 로그인 방법 > **이메일/비밀번호** 사용 설정.
3. 프로젝트 설정 > 내 앱 > 웹 앱 추가 → 나오는 설정값을 `assets/firebase-config.js`에 붙여 넣기.
4. Realtime Database > **규칙** 탭에 `database.rules.json` 내용을 붙여 넣고 게시.
   기존 kowoo-status 규칙이 있다면 `"rules": { ... }` 안에 `"cctv": { ... }` 블록만 추가하세요.
5. Authentication > 사용자 탭에서 계정을 만들고, 각 계정의 **UID**를 복사합니다.
6. Realtime Database > 데이터 탭에서 `cctv/roles/<UID>` 에 역할을 문자열로 넣습니다.

| 역할 | 할 수 있는 일 | 예 |
|---|---|---|
| `admin` | 카메라·설비 영역·분석 설정 변경, 계획정지, 보기 | 신욱중, 코우타이 생산관리 책임자 |
| `manager` | 계획정지 처리, 보기 | 코우타이 반장, 한국 본사 관리자 |
| `viewer` | 보기만 | 본사 임원 |
| `agent` | 분석 결과 올리기 (공장 분석 PC 전용 계정) | `cctv-pc1@kowoo...` |

> 역할이 없는 계정으로 로그인하면 화면에 UID가 표시됩니다. 그 UID를 위 경로에 등록하면 됩니다.

## 2단계. GitHub에 올리기 (대시보드 주소 만들기)

1. GitHub `appshin` 계정에 새 저장소 생성 (예: `kowoo-machine-watch`).
2. 이 폴더 전체를 올립니다. (`edge/go2rtc.yaml`, `*.exe` 는 `.gitignore`로 자동 제외 → CCTV 비밀번호가 올라가지 않음)
   ```bash
   git init && git add . && git commit -m "KOWOO Thai machine watch"
   git branch -M main
   git remote add origin https://github.com/appshin/kowoo-machine-watch.git
   git push -u origin main
   ```
3. 저장소 **Settings > Pages** > Source: `Deploy from a branch`, Branch: `main` / `(root)` 저장.
4. 1~2분 뒤 `https://appshin.github.io/kowoo-machine-watch/` 가 대시보드 주소입니다. 이 주소를 코우타이 관리자와 본사에 공유하세요.
5. Firebase Authentication > 설정 > **승인된 도메인**에 `appshin.github.io` 추가.

> 무료 GitHub 계정은 공개 저장소에서만 Pages가 됩니다. 코드는 공개되어도 로그인과 DB 규칙으로 데이터는 보호됩니다. 저장소를 비공개로 하려면 GitHub 유료 플랜이 필요합니다.

## 3단계. 공장 분석 PC 설정 (CCTV 프로그램이 떠 있는 PC)

CCTV 프로그램 화면을 웹이 직접 캡처해 박스별 **움직임 빈도**로 판정합니다. go2rtc나 CCTV 비밀번호는 필요 없습니다.

1. CCTV 프로그램을 **분할 화면 고정**으로 띄워 둡니다. 자동 순환(채널 전환)은 끕니다. 창을 최소화하지 마세요.
2. 같은 PC의 Chrome에서 `https://appshin.github.io/kowoo-machine-watch/analyzer.html` 을 엽니다.
3. admin 계정으로 로그인 → **카메라 추가** → 영상 입력 **CCTV 프로그램 화면** → 저장.
4. 카메라 칸의 **CCTV 화면 선택** → 공유 창 목록에서 CCTV 프로그램 **창**을 고르고 공유.
   - "전체 화면"보다 **창**을 고르세요. 창을 고르면 Chrome이 위에 겹쳐도 CCTV 화면이 그대로 캡처됩니다.
5. **감시 박스 편집** → 설비번호 입력 → 화면 위에 박스를 드래그 → **설비 저장**. 설비마다 반복.
6. **분석 시작**, **열면 자동 시작** 체크. 등록이 끝나면 agent 계정으로 다시 로그인해 운영합니다.

### CCTV 연결 전 시험하기 (시험용 CCTV)

카메라 추가에서 영상 입력을 **시험용 CCTV (사진·영상 파일)** 로 고르고, 카메라 칸의 **시험 파일 불러오기**로 파일을 고릅니다.

| 파일 | 정상 결과 |
|---|---|
| 공장 사진 (JPG·PNG) | 움직임이 없으므로 약 1분 뒤 모든 박스가 **빨강 0%** |
| 공장 영상 (MP4·WEBM) | 반복 재생되며, 사람·기계가 움직이는 박스는 **초록**, 정지된 곳은 **빨강** |

사진은 이 PC 브라우저에 저장되어 다시 열어도 유지되고, 영상은 페이지를 다시 열면 다시 골라야 합니다. 시험이 끝나면 **카메라 설정**에서 영상 입력만 **CCTV 프로그램 화면**으로 바꾸면 그려 둔 박스를 그대로 쓸 수 있습니다 (CCTV 화면 구도가 사진과 같을 때).

#### 실시간 웹캠 사이트로 시험

영상 입력 **시험용 웹 주소 (실시간 웹캠 사이트)** 를 고르고 주소를 넣습니다.

| 주소 종류 | 동작 |
|---|---|
| 직접 영상 주소 (`.m3u8`, `.mp4`, `.mjpg`, 스냅샷 `.jpg`) | 바로 분석. 사이트가 다른 웹의 영상 읽기를 막으면 아래 방식으로 안내 |
| 유튜브 등 일반 사이트 주소 | 카메라 칸의 **사이트 열기** → 새 창이 열리면 **CCTV 화면 선택**에서 그 창(탭)을 고름 |

두 번째 방식은 실제 CCTV 프로그램 창을 캡처하는 것과 같은 원리라, 운영 전 연습으로도 좋습니다. 사이트 창은 최소화하지 마세요.

### 한국에서 원격으로 박스 그리기

태국 분석 PC에서 분석 화면을 열고 **CCTV 화면 선택**까지만 해 두면, 나머지 박스 작업은 한국에서 할 수 있습니다.

1. 한국에서 대시보드(`https://appshin.github.io/kowoo-machine-watch/`)를 admin 계정으로 엽니다.
2. 카메라 칸에서 카메라를 고르면 태국 PC가 최신 화면을 2초마다 보내 줍니다.
3. 카메라 패널 오른쪽 위 **감시 박스 편집** → 화면 위에 박스를 그리고 **설비 저장**.
4. 태국 분석 PC는 저장된 박스를 바로 받아 분석합니다.

### 분할 화면(16분할 등)을 칸별로 쓰기

CCTV 프로그램(예: ADT-EYE)은 **분할 화면 그대로** 두고, 웹에서 칸별로 잘라 씁니다. CCTV 화면 선택은 PC에서 한 번만 하면 모든 카메라가 함께 씁니다.

1. 분석 화면 **분할 화면 나누기** → 영상 칸 전체(바깥 테두리)를 드래그 → 줄 수·칸 수(예: 4×4), 이름 앞부분(예: `진위 CH`) → **카메라 16개 만들기**.
2. 칸마다 카메라가 하나씩 생기고, 각 카메라는 그 칸만 크게 보여 줍니다. 필요 없는 칸(실외, 채널 없음)은 카메라 설정에서 삭제.
3. 한 대씩 따로 지정하려면 **카메라 설정 > 화면 영역 > 영역 지정**.
4. CCTV 프로그램에서 채널을 더블클릭해 크게 보거나 분할 배치·창 크기를 바꾸면 칸 위치가 어긋납니다. 그대로 두세요.
5. 칸 아래쪽 날짜·시간·LIVE 글자는 계속 바뀌므로 감시 구역에 넣지 마세요.

### 감시 구역 모양

- **사각형으로 그리기** 후 모서리 점을 끌어 설비 바닥선에 맞게 비스듬히 조절할 수 있습니다.
- **점 찍어 그리기**: 클릭으로 점을 찍고 첫 점을 다시 누르거나 더블클릭하면 닫힙니다.
- 선 위 더블클릭 = 점 추가, 점 더블클릭 = 점 삭제.
- 움직임은 **모양 안쪽만** 계산하므로, 통로를 구역 밖에 두면 지나가는 사람은 세지 않습니다.

### 판정 방식

1초마다 박스 안 화면을 직전 화면과 비교해 "움직임 있음/없음"을 기록하고, **최근 판단 시간(기본 5분) 중 움직임이 있던 비율**로 판정합니다.

| 설정 (박스마다) | 기본 | 의미 |
|---|---|---|
| 판단 시간 | 5분 | 이 기간의 기록으로 판정. 길수록 안정적, 짧을수록 빨리 반응 |
| 가동 기준 | 30% | 움직임 비율이 이 값 이상이면 **초록 50%**, 미만이면 **빨강 50%** (비가동 의심) |
| 민감도 | 5 | 높을수록 작은 움직임도 잡음. 멀리 있는 작은 박스는 7~8 |

- 비가동에서 가동으로 돌아오려면 기준 +5%p가 필요합니다 (경계값에서 깜빡임 방지).
- 기본값(5분/30%)이면 작업자가 계속 일하다 자리를 비운 뒤 **약 3분** 후 빨강으로 바뀝니다.
- 박스 오른쪽 위 **흰 점** = 지금 이 순간 움직임 감지. 민감도 맞출 때 보세요.
- 화면 전체가 한꺼번에 크게 바뀌는 순간(조명, 야간 흑백 전환)은 판정에서 뺍니다.

### 박스 그리는 위치

| 박스 위치 | 초록의 의미 |
|---|---|
| 작업자가 서서 일하는 자리 | 작업자가 있음 (작업자 미배치 감시) |
| 소재 투입부·배출 컨베이어·프레스 램 | 설비가 돌고 있음 (자동 투입 설비는 이쪽) |

경광등, CCTV 화면의 날짜·시계 글자, 사람이 자주 지나다니는 통로는 박스에 넣지 마세요.

### 무인 운영 (재부팅 후 자동 시작)

1. `edge\start-kowoo-screen.bat` 를 메모장으로 열어 `CCTV_WINDOW=` 뒤를 CCTV 프로그램 창 제목에 들어 있는 단어로 바꿉니다.
2. 바로가기를 `shell:startup` 폴더에 넣습니다. 부팅 20초 뒤 분석 화면이 열립니다.
3. (선택) `edge\allow-screen-capture.reg` 를 관리자 권한으로 실행하면 재부팅 후에도 클릭 없이 화면 캡처가 시작됩니다. 적용하지 않으면 재부팅 후 **CCTV 화면 선택**을 한 번 눌러야 하고, 그 전까지 대시보드에는 **신호없음**으로 표시됩니다.
4. Windows 절전 모드를 끕니다.

### (선택) CCTV 주소로 직접 연결

NVR RTSP 주소를 쓰려면 go2rtc 방식도 그대로 쓸 수 있습니다 (`edge\go2rtc.example.yaml`, `start-kowoo-cctv.bat`, 영상 입력 "CCTV 영상 (go2rtc)").
HDMI 캡처장치를 쓰면 영상 입력 **USB 웹캠 / HDMI 캡처장치**를 고르세요.

## 종합상황실 (room.html)

`https://appshin.github.io/kowoo-machine-watch/room.html` (대시보드 오른쪽 위 **종합상황실**)

- F1·F2·F3·창고 전체 카메라 중 **비가동 의심 설비만** 카드로 모아 보여 줍니다. 카드에는 그 설비 박스 주변을 확대한 실시간 화면(5초 간격), 경과시간, 계획정지 버튼이 있습니다.
- 영상 신호가 끊긴 카메라(분석 PC 꺼짐, 화면 미선택)도 따로 모여 나옵니다.
- 모두 정상이면 큰 초록 글씨로 "모든 설비가 가동 중입니다".
- 화면 크기 선택, 전체 화면, 알림음 버튼이 있어 사무실 벽 모니터에 띄워 두기 좋습니다.
- 확대 화면은 상황실이 열려 있을 때만 올라가므로 데이터 사용량이 적습니다.

## LINE 알림

분석 PC가 30초마다 확인해서, 비가동 의심이 정해진 시간(기본 10분) 이상 이어진 설비를 **한 메시지로 묶어** LINE으로 보냅니다.
LINE Notify는 2025년 3월 31일 종료되어 **LINE 공식계정 + Messaging API**를 씁니다. 공식계정 메시지는 "보낸 횟수 × 받는 사람 수"로 계산되므로(단체방도 인원수만큼), 무료 한도 안에서 쓰려면 지연·반복 시간을 넉넉히 잡으세요.

### 1) LINE 공식계정과 토큰

1. LINE Official Account Manager에서 공식계정을 만듭니다 (예: KOWOO THAI Alert).
2. 설정 > Messaging API 사용 → LINE Developers 콘솔에서 해당 채널을 엽니다.
3. Messaging API 탭에서 **Channel access token (long-lived)** 을 발급해 복사합니다.
4. 같은 탭의 "Allow bot to join group chats" 를 사용으로 바꿉니다 (단체방으로 받을 경우).
5. Official Account Manager > 응답 설정에서 **웹훅 사용**, 자동 응답 메시지는 끕니다.

### 2) 중계 스크립트 (구글 앱스 스크립트, 무료)

브라우저에서 LINE으로 바로 보낼 수 없어서 중간에 구글 앱스 스크립트를 둡니다. 토큰은 이 스크립트에만 저장되고 GitHub에는 올라가지 않습니다.

1. https://script.google.com → 새 프로젝트 → `edge/line-relay.gs` 내용을 통째로 붙여 넣고 저장.
2. 프로젝트 설정(톱니바퀴) > **스크립트 속성**에 세 개 추가:
   - `LINE_TOKEN` : 1)에서 복사한 토큰
   - `RELAY_KEY` : 아무 긴 문자열 (예: 영문+숫자 30자)
   - `REGISTER_CODE` : 등록용 문구 (예: `KOWOO-ALERT-7391`)
3. **배포 > 새 배포** → 유형 **웹 앱**, 실행 계정 **나**, 액세스 권한 **모든 사용자** → 배포 → 나오는 **웹 앱 URL** 복사.
4. LINE Developers > Messaging API 탭 > **Webhook URL** 에 그 웹 앱 URL을 넣고 저장, Use webhook 켜기.

### 3) 받는 사람 등록

- 단체방: 코우타이 관리자 LINE 단체방에 공식계정을 초대 → 단체방에서 `REGISTER_CODE` 문구를 그대로 입력 → "등록되었습니다" 답장이 오면 완료.
- 개인: 공식계정을 친구 추가 → 1:1 대화에서 `REGISTER_CODE` 입력.
- 해제: 같은 곳에서 `STOP` 입력.

### 4) 분석 화면에서 켜기

분석 화면(admin) **LINE 알림** → 중계 주소(웹 앱 URL), 중계 비밀키(`RELAY_KEY`와 같게) 입력 → **시험 메시지 보내기** → LINE에 도착하면 **알림 보내기** 체크 후 저장.

| 설정 | 기본 | 설명 |
|---|---|---|
| 알림 지연 | 10분 | 비가동 의심이 이 시간 이상 이어져야 알림 |
| 다시 알림 | 60분 | 계속 비가동이면 이 간격으로 다시 (0 = 한 번만) |
| 가동 복귀 알림 | 끔 | 켜면 메시지 수가 늘어남 |
| 알림 쉬는 시간 | 없음 | 점심·교대 시간 (태국 시간). 예: `12:00-13:00, 19:45-20:15` |
| 메시지 언어 | 태국어+한국어 | 머리글을 고른 언어로 함께 표시 |

### 데이터베이스 규칙 갱신

이번 버전은 `cctv/crops`, `cctv/alertLog`, `cctvAlert` 경로를 씁니다. Firebase 콘솔 > Realtime Database > 규칙에 새 `database.rules.json` 내용을 그대로 붙여 넣고 게시하세요 (기존 현황판 데이터 규칙 `$other`는 그대로 들어 있습니다).

## 대시보드 사용 (index.html)

- **맨 위 안돈 보드**: 구역별 모든 설비. 빨간 칸(깜빡임) = 작업자 없음, 초록 = 가동, 회색 줄무늬 = 계획정지, 노란 줄무늬 = 영상 신호 없음. 칸을 누르면 그 카메라 영상으로 이동.
- **지금 작업자 없는 설비**: 오래된 순서. 계획상 안 돌리는 설비는 **계획정지 처리** (manager 이상).
- **카메라 영상**: 빨간 박스 + 경과시간 표시. 보고 있는 동안만 영상이 전송됩니다.
- **근무조별 가동 현황**: 날짜·주간/야간을 골라 설비별 비가동 시간과 비율 확인.
- **알림음**: 켜 두면 새 비가동 설비가 생길 때 소리가 납니다 (현장 사무실 모니터용).
- 상단 시계: 태국 현지 시간과 한국 시간.

## 비용 (Firebase)

- 상태·통계·기록은 데이터가 아주 작아 무료(Spark) 플랜으로 충분합니다.
- **원격 영상**이 대부분을 차지합니다. 960px 프레임을 2초마다 보면 시청자 1명이 1시간에 약 100~130MB를 씁니다. Spark 무료 다운로드는 월 10GB입니다.
- 본사·현지에서 영상을 자주 본다면 **Blaze(종량제, GB당 약 1달러)** 로 바꾸거나, 분석 설정에서 원격 영상 가로 크기를 640, 주기를 3000ms로 낮추세요.

## 정확도와 한계

- 움직임 감지는 "사람"이 아니라 "박스 안 화면이 바뀌었는지"를 봅니다. 박스 위치가 판정의 의미를 정합니다.
- 작업자가 거의 움직이지 않고 서서 지켜보는 공정은 움직임 비율이 낮게 나올 수 있습니다. 가동 기준을 15~20%로 낮추세요.
- 지게차·다른 작업자가 잠깐 지나가는 것은 빈도 판정으로 대부분 걸러집니다.
- CCTV 분할 화면이 16분할처럼 작으면 박스도 작아집니다. 민감도를 올리거나 4~9분할을 쓰세요.

## 개인정보 (태국 PDPA)

- 영상은 분석 PC 안에서 처리하고, 원격 시청용 최신 1장만 덮어쓰며 녹화하지 않습니다. 이벤트 기록에는 이미지가 없습니다.
- 그래도 작업장 모니터링에 해당하므로 현장에 CCTV 안내 표지를 붙이고, 직원에게 **목적(설비 가동 관리)·처리 범위**를 태국어로 공지해 두는 것이 좋습니다. 필요하면 현지 노무/법무 담당자와 확인하세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 카메라 칸에 "화면 선택 필요" | **CCTV 화면 선택**을 눌러 CCTV 프로그램 창을 다시 고르기 (CCTV 프로그램을 껐다 켜면 필요) |
| 대시보드 전체가 "신호없음" | 분석 PC가 꺼졌거나, 분석 중지, 화면 미선택, 인터넷 끊김 |
| 작업 중인데 빨강 | 민감도 올리기, 가동 기준 낮추기, 박스를 움직임 생기는 곳으로 옮기기 |
| 아무도 없는데 초록 | 박스 안에 경광등·통로·시계 글자가 있는지, 민감도 낮추기 |
| 박스 위치가 어긋남 | CCTV 프로그램의 분할 배치나 창 크기가 바뀜 → 원래대로 되돌리거나 박스 다시 그리기 |
| 로그인 후 UID가 표시되며 막힘 | `cctv/roles/<UID>` 등록 필요 |
