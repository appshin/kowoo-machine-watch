# 코우타이 설비 가동 감시 (KOWOO Thai Machine Watch)

공장 CCTV 영상에서 **설비 앞 작업자 위치에 사람이 없는 설비**를 실시간으로 찾아 빨간 박스로 표시하고,
코우타이 관리자와 한국 본사가 같은 화면(GitHub Pages)에서 보면서 관리하는 웹입니다.

## 구성

```
[CCTV/NVR] --RTSP--> [공장 분석 PC]
                       go2rtc (영상 변환, 127.0.0.1 전용)
                       analyzer.html (Chrome, 사람 인식 + 설비별 판정)
                            |
                            v
                   Firebase Realtime Database (asia-southeast1)
                   상태 / 이벤트 / 근무조 통계 / 보고 있을 때만 영상 프레임
                            ^
                            |
     [GitHub Pages] index.html  <-- 코우타이 관리자 (PC, 휴대폰), 한국 본사
```

- **판정 방식**: 설비마다 "설비 박스"와 "작업자 위치"를 영상 위에 그려 두면, 작업자 위치에 사람이 정해진 시간(기본 60초) 이상 없을 때 그 설비를 **비가동(빨간 박스)** 으로 표시합니다.
- **사람 인식**: Google MediaPipe(EfficientDet) 모델이 분석 PC의 브라우저 안에서 돌아갑니다. 영상이 외부 서버로 나가지 않습니다.
- **원격 영상**: 대시보드에서 누군가 해당 카메라를 보고 있을 때만 2초마다 한 장씩 올라갑니다. 영상은 저장되지 않고 최신 1장만 덮어씁니다.
- **기록**: 비가동 시작/종료 이벤트, 근무조(주간 08–20시 / 야간 20–08시, 현지시간)별 설비별 가동·비가동 시간.
- **계획정지**: 생산계획상 돌리지 않는 설비는 대시보드에서 "계획정지 처리"하면 빨간 표시와 통계에서 빠집니다.
- **언어**: 한국어 / English / ไทย (화면 오른쪽 위에서 전환)

| 파일 | 역할 |
|---|---|
| `index.html` | 관리 대시보드 (안돈 보드, 실시간 영상, 비가동 목록, 근무조 통계, 기록) |
| `analyzer.html` | 공장 분석 PC 전용 화면 (카메라 등록, 설비 영역 그리기, 분석 실행) |
| `assets/firebase-config.js` | Firebase 설정값, 근무조 시각, 구역(F1/F2/F3/창고) |
| `database.rules.json` | DB 보안 규칙 |
| `edge/` | 분석 PC용 go2rtc 설정 예시, 자동 시작 배치파일 |

---

## 1단계. Firebase 준비

기존 `kowoo-status` 프로젝트를 같이 써도 되고 새 프로젝트를 만들어도 됩니다. 데이터는 모두 `cctv/` 아래에 들어가서 기존 데이터와 겹치지 않습니다.

1. Firebase 콘솔 > **Realtime Database** 생성 (위치: `asia-southeast1` 싱가포르).
2. **Authentication** > 로그인 방법 > **이메일/비밀번호** 사용 설정.
3. 프로젝트 설정 > 내 앱 > 웹 앱 추가 → 나오는 설정값을 `assets/firebase-config.js`에 붙여 넣기.
4. Realtime Database > **규칙** 탭에 `database.rules.json` 내용을 붙여 넣고 게시.
   기존 kowoo-status 규칙이 있다면 `"rules": { ... }` 안에 `"cctv": { ... }` 블록만 추가하세요.
5. Authentication > 사용자 탭에서 계정을 만들고, 각 계정의 **UID**를 복사합니다.
6. Realtime Database > 데이터 탭에서 `cctv/roles/<UID>` 에 역할을 문자열로 넣습니다.

| 역할 | 할 수 있는 일 | 예 |
|---|---|---|
| `admin` | 카메라·설비 영역·분석 설정 변경, 계획정지, 보기 | 신욱중, 코우타이 생산관리 책임자 |
| `manager` | 계획정지 처리, 보기 | 코우타이 반장, 한국 본사 관리자 |
| `viewer` | 보기만 | 본사 임원 |
| `agent` | 분석 결과 올리기 (공장 분석 PC 전용 계정) | `cctv-pc1@kowoo...` |

> 역할이 없는 계정으로 로그인하면 화면에 UID가 표시됩니다. 그 UID를 위 경로에 등록하면 됩니다.

## 2단계. GitHub에 올리기 (대시보드 주소 만들기)

1. GitHub `appshin` 계정에 새 저장소 생성 (예: `kowoo-machine-watch`).
2. 이 폴더 전체를 올립니다. (`edge/go2rtc.yaml`, `*.exe` 는 `.gitignore`로 자동 제외 → CCTV 비밀번호가 올라가지 않음)
   ```bash
   git init && git add . && git commit -m "KOWOO Thai machine watch"
   git branch -M main
   git remote add origin https://github.com/appshin/kowoo-machine-watch.git
   git push -u origin main
   ```
3. 저장소 **Settings > Pages** > Source: `Deploy from a branch`, Branch: `main` / `(root)` 저장.
4. 1~2분 뒤 `https://appshin.github.io/kowoo-machine-watch/` 가 대시보드 주소입니다. 이 주소를 코우타이 관리자와 본사에 공유하세요.
5. Firebase Authentication > 설정 > **승인된 도메인**에 `appshin.github.io` 추가.

> 무료 GitHub 계정은 공개 저장소에서만 Pages가 됩니다. 코드는 공개되어도 로그인과 DB 규칙으로 데이터는 보호됩니다. 저장소를 비공개로 하려면 GitHub 유료 플랜이 필요합니다.

## 3단계. 공장 분석 PC 설치 (Windows)

CCTV(RTSP)는 브라우저가 직접 못 읽기 때문에, 공장 PC에서 **go2rtc**가 영상을 브라우저용으로 바꿔 줍니다.

**권장 사양**: 카메라 4~8대 기준 i5급 이상 + 내장/외장 그래픽, RAM 8GB, Windows 10/11, Chrome. 유선 LAN으로 NVR과 같은 네트워크.

1. 이 저장소를 PC에 내려받기 (`git clone` 또는 ZIP 다운로드 후 압축 해제). 예: `C:\kowoo-machine-watch`
2. [go2rtc 릴리스](https://github.com/AlexxIT/go2rtc/releases)에서 `go2rtc_win64.zip` 을 받아 `go2rtc.exe`를 `edge\` 폴더에 넣기.
   스냅샷 방식을 쓸 경우에만 ffmpeg가 필요합니다 (`ffmpeg.exe`를 같은 폴더에).
3. `edge\go2rtc.example.yaml` 을 `edge\go2rtc.yaml` 로 복사하고 카메라 RTSP 주소를 입력.
   - **서브스트림(저해상도, H.264)** 을 쓰세요. 640×360~1280×720이면 충분합니다.
   - 카메라/NVR 설정에서 서브스트림 코덱이 H.265면 H.264로 바꾸세요.
4. `edge\start-kowoo-cctv.bat` 실행 → go2rtc와 Chrome 분석 화면(`http://localhost:1984/analyzer.html`)이 열립니다.
5. `agent` 계정(카메라·설비 등록할 때는 `admin` 계정)으로 로그인.
6. 배치파일 바로가기를 `shell:startup` 폴더에 넣으면 PC 재부팅 후 자동 실행됩니다. 분석 화면의 **열면 자동 시작**도 체크하세요.
7. Windows 전원 설정에서 **절전 모드 사용 안 함**.

> 분석 화면은 반드시 `http://localhost:1984/analyzer.html` 로 여세요. GitHub Pages(https) 주소에서는 보안 정책 때문에 CCTV 영상을 읽을 수 없습니다 (USB 웹캠은 예외).

## 4단계. 카메라와 설비 등록

분석 PC의 `analyzer.html` 에서 (admin 계정):

1. **이 PC 이름** 확인 (예: `PC-F1`). 건물마다 PC를 따로 두면 이름을 다르게 하세요.
2. **카메라 추가** → 카메라 이름, 기본 구역(F1/F2/F3/창고), 담당 PC 이름, 영상 입력 `CCTV 영상 (go2rtc)`, go2rtc 스트림 이름(`f1_cam1` 등) 입력 후 저장.
3. 카메라 영상이 나오면 **설비 영역 편집** →
   - 설비번호 입력 (작업자 배치표와 같은 **설비고유번호**로 맞추면 관리가 쉽습니다)
   - **설비 박스 그리기**: 설비 전체를 드래그 (빨간 박스가 표시될 영역)
   - **작업자 위치 그리기**: 작업자가 서서 일하는 자리를 드래그. 사람 몸 전체가 들어가게 넉넉히.
   - 작업자 부재 판정 시간: 기본 60초. 자재 가지러 자주 자리를 비우는 공정은 120~180초.
   - **설비 저장**. 다음 설비는 **새 설비**.
4. **분석 시작**. 각 타일에 사람 박스(파란색)와 설비 상태(초록/빨강)가 보이면 정상입니다.

## 대시보드 사용 (index.html)

- **맨 위 안돈 보드**: 구역별 모든 설비. 빨간 칸(깜빡임) = 작업자 없음, 초록 = 가동, 회색 줄무늬 = 계획정지, 노란 줄무늬 = 영상 신호 없음. 칸을 누르면 그 카메라 영상으로 이동.
- **지금 작업자 없는 설비**: 오래된 순서. 계획상 안 돌리는 설비는 **계획정지 처리** (manager 이상).
- **카메라 영상**: 빨간 박스 + 경과시간 표시. 보고 있는 동안만 영상이 전송됩니다.
- **근무조별 가동 현황**: 날짜·주간/야간을 골라 설비별 비가동 시간과 비율 확인.
- **알림음**: 켜 두면 새 비가동 설비가 생길 때 소리가 납니다 (현장 사무실 모니터용).
- 상단 시계: 태국 현지 시간과 한국 시간.

## 비용 (Firebase)

- 상태·통계·기록은 데이터가 아주 작아 무료(Spark) 플랜으로 충분합니다.
- **원격 영상**이 대부분을 차지합니다. 960px 프레임을 2초마다 보면 시청자 1명이 1시간에 약 100~130MB를 씁니다. Spark 무료 다운로드는 월 10GB입니다.
- 본사·현지에서 영상을 자주 본다면 **Blaze(종량제, GB당 약 1달러)** 로 바꾸거나, 분석 설정에서 원격 영상 가로 크기를 640, 주기를 3000ms로 낮추세요.

## 정확도와 한계

- 이 시스템은 "작업자가 자리에 있는가"를 봅니다. 작업자는 있지만 설비가 멈춘 경우(자재 대기, 고장)는 초록으로 보입니다. 실제 가동 여부까지 보려면 경광등 색 인식이나 설비 신호(PLC·전류센서) 연동을 추가해야 합니다.
- 카메라는 작업자 자리가 가리지 않게, 비스듬히 위에서 내려다보는 각도가 가장 잘 인식됩니다. 정면 기둥·설비에 사람이 가려지면 비가동으로 잘못 나올 수 있으니 판정 시간을 늘리거나 카메라를 옮기세요.
- 멀리 있는 작은 사람은 **설비 주변 확대 인식**(기본 켜짐)이 도움이 됩니다. 그래도 놓치면 분석 설정에서 모델을 **정확(Lite2)** 으로, 최소 신뢰도를 0.25~0.3으로 낮춰 보세요.
- 지나가는 사람이 작업자 위치를 스쳐도 그 순간은 "가동"으로 잡힙니다. 작업자 위치를 너무 넓게 그리지 마세요.

## 개인정보 (태국 PDPA)

- 영상은 분석 PC 안에서 처리하고, 원격 시청용 최신 1장만 덮어쓰며 녹화하지 않습니다. 이벤트 기록에는 이미지가 없습니다.
- 그래도 작업장 모니터링에 해당하므로 현장에 CCTV 안내 표지를 붙이고, 직원에게 **목적(설비 가동 관리)·처리 범위**를 태국어로 공지해 두는 것이 좋습니다. 필요하면 현지 노무/법무 담당자와 확인하세요.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 분석 화면 타일이 "영상 없음" | go2rtc 창이 떠 있는지, `go2rtc.yaml` 스트림 이름과 카메라 등록 이름이 같은지, 서브스트림이 H.264인지 |
| 화면에 go2rtc 기본 페이지가 뜸 | 배치파일로 실행했는지 확인 (저장소 폴더에서 실행해야 `static_dir: "."` 이 맞음) |
| 대시보드 전체가 "신호없음" | 분석 PC가 꺼졌거나 분석 중지 상태, 인터넷 끊김 |
| 사람이 있는데 빨강 | 작업자 위치를 넓히기, 판정 시간 늘리기, 모델 Lite2, 최소 신뢰도 낮추기 |
| 로그인 후 UID가 표시되며 막힘 | `cctv/roles/<UID>` 등록 필요 |
| 분석 PC에서 창을 최소화하면 멈춤 | 반드시 `start-kowoo-cctv.bat` 로 실행 (백그라운드 절전 해제 옵션 포함) |
